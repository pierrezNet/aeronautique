SELCAL system

    Optionally, click the buttons to change one of the 4 letters. When you play the code, you will hear two dual tones. For example, code ABCD is made of a first dual tone (two sounds at 312.6 and 346.7 hertz) followed by a second one (384.6 and 426.6 hertz).

    SELCAL is a selective calling system that lets a ground operator alert an aircraft crew that they wish to contact them. Each aircraft is assigned a 4-letter code made of two audio dual tones.

    Share a code

    The “Copy link” button gives the address of this page with the code shown, for example aeronautique.xyz/en/selcal/?code=AB-CD. Whoever opens it gets that code straight away, ready to be played.

    Embed SELCAL on your website

    A small standalone player with a transparent background shows the code and plays it when clicked. To add it to your page, copy this line (it uses the code shown above):

    <iframe src="https://aeronautique.xyz/selcal/embed.html?code=AB-CD" width="320" height="140" title="SELCAL AB-CD" style="border:0"></iframe>

    Add &theme=dark to the address to force the dark theme, or &theme=light for the light theme; otherwise the player follows the device setting. Likewise, &lang=en or &lang=fr sets the player language, which otherwise follows the browser. The only condition: credit the author with a link to aeronautique.xyz.
