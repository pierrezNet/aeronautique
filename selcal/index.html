Système SELCAL

    En option, cliquez sur les boutons pour changer l'une des 4 lettres. Si vous écoutez le code, vous entendrez deux bi-tonalités. Exemple, le code ABCD sera constitué d'une première bitonalité (2 sons de fréquence 312.6 et 346.7 hertz) puis d'une seconde (384.6 et 426.6 hertz).

    Le système Selcal est un système d'appel sélectif permettant à un opérateur au sol d'avertir un équipage d'un aéronef qu'il souhaite le contacter. Chaque appareil se voit attribuer un code en 4 lettres qui forme un code à deux bi-tonalités audio.

    Partager un code

    Le bouton « Copier le lien » donne l'adresse de cette page avec le code affiché, par exemple aeronautique.xyz/selcal/?code=AB-CD. La personne qui l'ouvre retrouve directement ce code, prêt à être écouté.

    Intégrer le SELCAL sur votre site

    Un petit lecteur autonome, à fond transparent, affiche le code et le joue au clic. Pour l'ajouter à votre page, copiez cette ligne (elle reprend le code affiché ci-dessus) :

    <iframe src="https://aeronautique.xyz/selcal/embed.html?code=AB-CD" width="320" height="140" title="SELCAL AB-CD" style="border:0"></iframe>

    Ajoutez &theme=dark à l'adresse pour forcer le thème sombre, ou &theme=light pour le thème clair ; sans précision, le lecteur suit le réglage de l'appareil. Seule condition : citer l'auteur avec un lien vers aeronautique.xyz.
